Current priority remains:

`5 Models RUN → manual TimesFM comparison for each model → identify problems / improvement candidates → Walk-forward & OOS validation → Independent QA → Director approval → Production`

## High-value research areas

1. Alternative-data taxonomy and dataset selection.
2. Data quality, preprocessing, sampling and outlier handling.
3. Feature engineering for investment signals.
4. Supervised ML: regression and classification.
5. Unsupervised ML: clustering and factor analysis.
6. Deep / reinforcement learning as research candidates, not automatic Production additions.
7. Trading-strategy backtesting and comparative evaluation.
8. Transaction-cost-aware evaluation.
9. Out-of-sample validation and defenses against overfitting / in-sample bias.
10. Incremental-alpha testing of alternative data versus traditional inputs.

## Model relevance — initial mapping

- HIPM: nonlinear/classification signals and suitable alternative/intraday data research.
- HISM: clustering, factor analysis and regime-classification research.
- BCVM: fundamental + alternative-data combination research.
- HFGM: factor analysis and ML ranking research.
- HAPM: nonlinear classification and alternative-signal research.
