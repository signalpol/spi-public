## Adopted operating principles
1. **Continuous Improvement** — Treat models as systems requiring repeated testing and improvement as markets and data change.
2. **Signal vs Noise Discipline** — A discovered pattern is not automatically alpha; test whether it is persistent signal rather than noise.
3. **New Data / New Signal → Test → Production** — New datasets, machine-learning methods, and signals enter as research/challenger candidates, not direct Production changes.
