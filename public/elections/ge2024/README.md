# 제22대 국회의원선거 공식 개표결과 정규화본

이 디렉터리는 중앙선거관리위원회 시도별 개표현황을 통합·정규화한 공개 배포용 결과를 관리한다.

## 범위

- 선거: 제22대 국회의원선거
- 선거일: 2024-04-10
- 시도: 17개
- 지역구: 254개
- 후보자: 693명
- 지역구별 당선자 유일성 오류: 0건

## 지역구 의석 재현

- 더불어민주당 161석
- 국민의힘 90석
- 진보당 1석
- 개혁신당 1석
- 새로운미래 1석

## 저장소 구분

- `spi-public`: 공개 가능한 공식결과 정규화본과 배포용 산출물
- `spi-spin`: SEFM-GE 엔진, 백테스트 코드, 내부 검증 및 개발 기록

이 결과 파일은 백테스트의 사후 평가 정답지이며, 예측 입력으로 사용해서는 안 된다.
